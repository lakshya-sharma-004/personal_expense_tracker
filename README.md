# Personal Finance & Expense Tracker

An Excel-based personal finance management system designed to track income, expenses, monthly budgets, and savings through automated calculations and interactive dashboards.

## Features
- Record and categorize income and expenses.
- Track monthly spending and savings.
- Monitor budgets against actual expenses.
- Visualize financial data using charts and dashboards.
- Analyze monthly income, expenses, and savings trends.

## Technologies Used
- Microsoft Excel
- Excel Formulas (SUMIFS, COUNTIFS, IF, IFERROR)
- Data Validation
- Conditional Formatting
- Excel Charts

## Workbook Sheets
- **Dashboard:** Financial overview and visualizations.
- **Transactions:** Income and expense records.
- **Categories:** Transaction categories.
- **Monthly Budget:** Budget planning and tracking.
- **Analysis:** Monthly and category-wise summaries.
- **Settings:** Dashboard configuration.

## How to Use
1. Download the `.xlsx` workbook.
2. Open it using Microsoft Excel.
3. Enter your transactions in the Transactions sheet.
4. Configure the reporting month in Settings.
5. View your financial summaries in the Dashboard.

## Project Purpose
This project was developed as an MCA mini project to demonstrate the practical application of Microsoft Excel in financial tracking, data analysis, and dashboard visualization.
